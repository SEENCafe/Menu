# منوی کافه سین

سایت منو در آدرس ثابت زیر منتشر می‌شود (از طریق GitHub Pages) و تغییری در آن ایجاد نشده:

```
https://seencafe.github.io/Menu/
```

- `index.html` — صفحه عمومی منو برای مشتری‌ها.
- `admin.html` — پنل مدیریت (ورود با ایمیل/رمز عبور) برای ویرایش آیتم‌ها و قیمت‌ها، و ایمپورت از اکسل.

داده‌های منو در **Firebase (Firestore + Authentication)** ذخیره می‌شوند؛ یعنی خود سایت همچنان به‌صورت استاتیک روی GitHub Pages میزبانی می‌شود و آدرس آن تغییر نمی‌کند، فقط داده‌های منو و ورود ادمین از طریق Firebase مدیریت می‌شود.

## راه‌اندازی Firebase (یک‌بار، حدود ۱۰ دقیقه)

1. به [console.firebase.google.com](https://console.firebase.google.com) بروید و با یک حساب Google، یک پروژه جدید بسازید (مثلاً با نام `seen-cafe`).
2. از منوی سمت راست، **Build > Firestore Database** را باز کنید و روی «Create database» بزنید. حالت را روی **Production mode** بگذارید (منطقه/Region دلخواه، ترجیحاً نزدیک‌ترین به ایران مثل `eur3` یا هر گزینه پیش‌فرض).
3. از منوی سمت راست، **Build > Authentication** را باز کنید، تب **Sign-in method** را باز کرده و روش **Email/Password** را فعال کنید.
4. در تب **Users** همان صفحه Authentication، روی «Add user» بزنید و یک ایمیل و رمز عبور برای ادمین بسازید (مثلاً `admin@seencafe.ir` و یک رمز قوی). این همان حساب ثابتی است که با آن وارد `admin.html` می‌شوید؛ رمز را هر زمان خواستید از همین صفحه می‌توانید تغییر دهید.
5. در تب **Rules** بخش Firestore Database، محتوای فایل [`firestore.rules`](firestore.rules) این پروژه را جایگزین قوانین فعلی کنید و «Publish» بزنید. این قانون تضمین می‌کند منو برای همه قابل مشاهده باشد ولی فقط کاربر واردشده (ادمین) بتواند آن را تغییر دهد.
6. به **Project settings** (چرخ‌دنده کنار «Project Overview») بروید، پایین صفحه بخش «Your apps» را پیدا کنید و یک اپ وب (`</>`) اضافه کنید (نیازی به Firebase Hosting نیست، فقط اپ وب کافیست). مقادیر `firebaseConfig` نمایش داده‌شده را کپی کنید.
7. این مقادیر را در فایل [`js/firebase-config.js`](js/firebase-config.js) جایگزین مقادیر `YOUR_...` کنید و تغییرات را کامیت/پوش کنید.

بعد از این مراحل:
- صفحه `admin.html` را باز کنید، با ایمیل/رمزی که در مرحله ۴ ساختید وارد شوید.
- چون در ابتدا هیچ داده‌ای در Firestore نیست، پنل به‌صورت خودکار منوی فعلی سایت را به‌عنوان نقطه شروع در ویرایشگر نمایش می‌دهد؛ کافیست یک‌بار روی «ذخیره تغییرات» بزنید تا در Firestore ذخیره شود.
- از این پس صفحه اصلی (`index.html`) منو را مستقیماً از Firestore می‌خواند، پس هر تغییری در پنل مدیریت، بلافاصله (بعد از رفرش صفحه مشتری) روی سایت اصلی دیده می‌شود.

## ایمپورت از اکسل

در پنل مدیریت:
1. روی «دانلود قالب اکسل» بزنید تا فایل نمونه با ستون‌های `دسته‌بندی`، `آیکون دسته (اختیاری)`، `نام آیتم`، `قیمت` دانلود شود.
2. فایل را با آیتم‌های خودتان پر کنید (هر ردیف = یک آیتم؛ آیتم‌های یک دسته‌بندی را زیر هم بنویسید).
3. از «انتخاب فایل اکسل» همان فایل را آپلود کنید. محتوای وارد‌شده در ویرایشگر جایگزین می‌شود (قابل بازبینی/ویرایش قبل از ذخیره نهایی).
4. برای ثبت نهایی روی «ذخیره تغییرات» کلیک کنید.

## نکات امنیتی

- مقادیر داخل `js/firebase-config.js` کلید مخفی نیستند و قرارگرفتن‌شان در کد عمومی طبیعی است؛ امنیت واقعی توسط **Firestore Rules** (مرحله ۵) و **Firebase Authentication** تضمین می‌شود، نه پنهان‌بودن این مقادیر.
- اگر پیش از تنظیم Firebase صفحه `admin.html` باز شود، پیام «Firebase پیکربندی نشده» نمایش داده می‌شود و صفحه عمومی منو نیز از داده‌های پیش‌فرض داخل `js/menu-data.js` استفاده می‌کند (تا سایت هیچ‌وقت خراب یا خالی دیده نشود).
